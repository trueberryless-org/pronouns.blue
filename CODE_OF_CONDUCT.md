# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

- Be respectful and constructive.
- Assume good intent.
- Avoid harassment, discrimination, and personal attacks.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of conduct and may remove, edit, or reject comments, commits, code, issues, and other contributions that are not aligned with it.

## Reporting

To report unacceptable behavior, please open a private security/reporting channel via the process in [SECURITY.md](./SECURITY.md).
